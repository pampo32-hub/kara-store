# Kara Store (ÉPURE Atelier)

Boutique digital de moda y catálogo interactivo. Desarrollado con React 19, TypeScript, Vite y Tailwind CSS.

## Desarrollo Local

```bash
npm install
npm run dev
```

La aplicación estará disponible en `http://localhost:3000`.

## Compilación para Producción

```bash
npm run build
```

Los archivos estáticos generados se ubican en la carpeta `dist/`.

## Despliegue en Render (Static Site)

1. **Build Command:** `npm run build`
2. **Publish Directory:** `dist`
